# 이잘키 데이터 출처와 갱신 원칙

사용자 지정일: 2026-10-25.

## 지정 출처

이잘키 기준 수치의 출처는 아래 아카라이브 문서 하나로 한정한다.

https://arca.live/w/wutheringwaves/%EC%9D%B4%EC%A0%95%EB%8F%84%EB%A9%B4%20%EC%9E%98%ED%82%A4%EC%9B%A0%EB%8B%A4%ED%91%9C

- 다른 사이트, 오버레이 저장소, 공략의 수치를 이잘키 수치로 가져오거나 누락 항목을 보완하지 않는다.
- 원문에 없는 캐릭터나 스탯은 미등록으로 구분한다. 임의 수치를 이잘키로 표시하지 않는다.
- 숫자와 함께 무기, 재련, 주옵션, 세트 구성, 버프 조건, 범위와 주석을 보존한다.
- 원문 수치와 사이트에서 계산하는 준종결·종결 목표는 구분한다. 계산 규칙을 변경해도 원문 수치를 덮어쓰지 않는다.

## 갱신 방식

- 사용자가 이잘키 데이터 갱신을 별도로 요청할 때만 원문을 다시 확인하고 반영한다.
- 주기적 크롤링, 배포 시 갱신, 백그라운드 보완을 추가하지 않는다.
- 반영 시 원문을 실제로 확인한 날짜와 조건별 변경 내역을 기록한다. 확인되지 않은 수정일이나 출처를 기재하지 않는다.

## 저장 원문에서 추출한 데이터

2026-10-25에 사용자가 제공한 저장 HTML을 로컬에서 읽어 표 135개, 캐릭터 항목 45개를 추출했다.
`frontend/src/datas/buildTargets/arca-snapshot.json`에 원문의 스탯 문자열, 범위와 조건, 장비 표, 추천 무기, 참고사항을 보존한다.
저장 문서에 표시된 수정 시각은 `2026-10-09 19:13:37`이며 HTML의 datetime 속성은 `2026-10-09T10:13:37.000Z`이다.
원문 HTML의 SHA-256과 실제 추출일을 함께 저장한다. 저장 HTML의 스크립트는 실행하지 않고 표의 텍스트만 추출했다.

`frontend/src/datas/buildTargets/arca.ts`가 이 스냅샷을 사이트 기준값으로 변환한다. 이전 오버레이와 외부 공략의 기준값은 사용하지 않는다.
현재 캐릭터 60개 중 원문에 있는 45개만 등록되며 나머지 15개는 화면에 미등록으로 표시한다.

- `X`, `유효옵`, 빈 칸 등 숫자가 없는 스탯은 모든 단계에서 미등록으로 유지하고 달성 판정에서 제외한다. 명시된 숫자 `0`은 보존한다.
- 공명 효율 범위는 상한을 사용하고, 원문에 권장값이 명시된 경우 그 값을 사용한다. 조건별 수치를 확정할 수 없으면 미등록으로 남긴다.
- 무기·주옵션·세트 구성과 메인 에코 예외는 원문에 기재된 조건을 따른다. 기존 게임 데이터는 이름을 내부 ID에 연결하고 종결 목표를 계산하는 데만 사용한다.
- 원문에 1코 주옵션이 생략된 경우 임의로 공격력 주옵션을 채우지 않는다. 상위 단계 환산에는 조건에 맞는 현재 장비의 실제 주옵션을 사용하며, 장비가 비어 있으면 해당 환산값도 미등록이다.
- 이잘키는 원문 수치, 종결은 기존 사이트의 부옵 예산 규칙, 준종결은 두 값의 중간값으로 구분한다. 비교값과 종결 환산은 C0·R1이며 메인 에코 효과를 포함하고 모든 에코 세트 효과는 제외한다.
- 원문 출처·수정일·추출일·라이선스와 원문 메모를 화면에서 확인할 수 있다. 추출 표 데이터의 출처 표시는 `frontend/public/licenses/arca-yeejalky.txt`에 보존한다.
